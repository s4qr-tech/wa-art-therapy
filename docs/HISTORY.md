## 環境メモ
- クラウドセッションの作業フォルダは GitHub のコピー。外部サイトへの接続は制限あり。
- Mac は `git fetch && git reset --hard origin/main` で GitHub に同期済み。古い状態は `backup-mac-old` ブランチに退避（不要になれば `git branch -D backup-mac-old`）。
- Mac とクラウドの両方で編集するため、作業前に必ず `git pull`、作業後は push（ユーザーの指示があったとき）。
